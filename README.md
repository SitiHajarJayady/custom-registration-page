# custom-registration-page

## POP MART Custom Registration Form

A custom registration page designed to manage high-volume participant sign-ups for a limited-capacity POP MART event.

### Key Features:

- **Participant Details Collection**  
  Fields include:
  - Name (as per IC/Passport)  
  - Contact Number  
  - Registered Email Address  
  - Full NRIC/Passport Number (supports alphanumeric input)  
  - Date of Birth  
  - Country

- **Validation Rules & Restrictions**
  - Only **one registration per NRIC/Passport Number** is allowed
  - **Children below 12 years old are not eligible to register**
  - Email address must be valid and accessible, as the queue number is sent via email

- **Capacity Control**
  - System enforces a **2,000-person limit** for the event

- **Admin Tools**
  - Export page includes a **"Search" function** to filter and find records based on all available input fields

## 99 Residence Final Third Round "Walk Through Lucky Draw" RSVP Form

This custom RSVP form was built with a verification flow based on a unit owner master list to ensure secure and accurate participation for a gated community event.

### Key Features:
- **Step 1: Unit Number & Owner IC Verification**  
  Validates user input against a master list. If matched, the system auto-fills the unit and owner name, allowing the user to proceed.

- **Step 2: Duplicate Registration Prevention**  
  Prevents multiple registrations from the same unit. If a unit is already registered, other owners from the same unit can check who registered by re-verifying their IC and unit number.

- **Step 3: Email Confirmation**  
  Upon successful submission, a confirmation email is sent to the registered participant.
