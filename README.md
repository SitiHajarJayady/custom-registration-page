## 99 Residence Final Third Round "Walk Through Lucky Draw" RSVP Form

This custom RSVP form was built with a verification flow based on a unit owner master list to ensure secure and accurate participation for a gated community event.

### Key Features:
- **Step 1: Unit Number & Owner IC Verification**  
  Validates user input against a master list. If matched, the system auto-fills the unit and owner name, allowing the user to proceed.

- **Step 2: Duplicate Registration Prevention**  
  Prevents multiple registrations from the same unit. If a unit is already registered, other owners from the same unit can check who registered by re-verifying their IC and unit number.

- **Step 3: Email Confirmation**  
  Upon successful submission, a confirmation email is sent to the registered participant.
